About

I am a software engineer specializing in distributed systems, AI-powered applications, and scalable backend infrastructure. I enjoy building reliable systems that bring together machine learning, information retrieval, and real-time data processing to solve complex engineering and business problems.

Distributed Systems & AI Engineering

At ProRata AI, I build AI-driven advertising systems spanning semantic retrieval, machine learning classification, real-time optimization, and LLM-powered agents. My work includes scaling vector similarity retrieval to serve millions of ad impressions per day, developing transformer-based content classification pipelines, and building event-driven feedback systems that adapt ad-serving strategies using real-time engagement signals. I have also worked on agentic applications using retrieval- augmented generation (RAG), vector databases, and LangGraph to power advertiser-facing product discovery and recommendations.

Previously, at Microsoft, I worked on Azure DNS, a critical cloud networking service handling high-volume customer requests. I designed and shipped control-plane capabilities, API validation systems, and developer tooling across the Azure ecosystem. These experiences strengthened my foundations in distributed systems, cloud infrastructure, API design, and building reliable production software with rigorous testing.

Across both roles, I focus on engineering systems that are scalable, observable, and dependable—from low-level backend infrastructure to AI applications evaluated for correctness and quality.
